# Joe Nasr — Five Creative Modes

A one-page multimedia portfolio for Joe Ribal Nasr.

The site presents one multidisciplinary practice through five distinct interaction systems:

1. **Direct** — creative direction, campaigns, brand systems, film and motion
2. **Build** — 3D, games, WebXR, prototypes and interactive systems
3. **Sound** — composition, guitar, audio post and commercial music
4. **Teach** — university, government and corporate training
5. **Venture** — RoboMarket, RoboCreate, Ideavent and Apex Innovate

## Design principles

- No generic portfolio cards or template-style section repetition
- Different visual grammar for each discipline with one persistent navigation system
- Mobile is intentionally redesigned rather than scaled down
- No audible autoplay
- Reduced-motion support
- Keyboard-accessible links and controls
- Quick View for recruiters and low-motion browsing
- No framework or runtime dependency

## Run locally

Open `index.html`, or serve the directory:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment

The repository is static and deploys directly to GitHub Pages or Vercel.
